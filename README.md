# Сайт alex-belyakov.com — техническая документация

Этот файл — справка для владельца сайта (не программиста) и для новой сессии Claude Code, чтобы быстро понять структуру, историю и планы проекта без необходимости пересматривать всю переписку.

## 1. Общее описание

- **Что это:** международная главная страница Александра Белякова — специалиста по digital-маркетингу и платному трафику (Яндекс Директ + Google Ads), а не только по Директу. Собрана 2026-09-14 по текстовому прототипу v1.2 (бриф лежит вне репозитория: `D:\My Docs\My Agency\alex-belyakov.com\Международный сайт\Главная страница alex-belyakov прототип v1.2.docx`).
- **История:** сайт прошёл два этапа за один день. Сначала (см. раздел 9) он был полностью склонирован с `direct.alex-belyakov.com` как рабочий каркас — дизайн-система, формы, интеграции. Затем `index.html` этого каркаса был **перенесён в `/direct/`** (как есть, под свою прежнюю позиционировку «эксперт по Яндекс Директу»), а на корневом `index.html` собрана **новая, отдельная международная главная** — про оба канала (Директ + Google Ads), без цен, с маршрутизацией «Россия / не Россия», кейсами с фильтрами, компаниями, нишами и т.д. `/direct/` при этом продолжает работать как отдельная специализированная посадочная для российского рынка.
- **Домен:** `alex-belyakov.com` (`CNAME` в корне). Есть открытый вопрос по домену для будущей EN-версии — см. раздел 10.
- **Репозиторий:** https://github.com/Aleksandr-Beliakov/alex-belyakov-com
- **Хостинг:** GitHub Pages, статический сайт без сборки.
- **Шрифт:** Google Fonts «Golos Text».
- **Стиль вёрстки:** инлайн `style="..."` прямо в HTML. В `css/style.css` — только адаптивные media-запросы и именованные многоразовые компоненты (попапы, FAQ-аккордеон, карусели, сетки, чипы).
- **Источник дизайн-системы:** `D:\My Docs\My Agency\alex-belyakov.com\Документация по сайту\Design System сайта - Беляков.md` — актуальна для всех вариантов сайта (корень, `/direct/`, будущий `/en/`).

```

/direct/                    — специализированная посадочная по Яндекс Директу для российского рынка.
  /direct/index.html         — точная копия боевой direct.alex-belyakov.com на момент 2026-09-14 (см. раздел 9),

  /direct/cases/case-1.html, case-2.html, case-3.html — заглушки трёх кейсов (те же, что были в /cases/ раньше)
  /direct/js/forms.js         — копия корневого forms.js + восстановлен вызов цели Метрики `ym(111606163, 'reachGoal', ...)`
  /direct/js/cookie-consent.js — копия корневого cookie-consent.js, но гейтит **Яндекс.Метрику** (id 111606163), а не GTM — точно как было на live direct.alex-belyakov.com

/css/style.css               — общие стили для ВСЕХ вариантов сайта (root, /direct/, будущий /en/)
/js/main.js                  — общий интерфейс (FAQ, попапы, слайдеры, лайтбокс, мобильное меню) + новая логика
                                 международной главной: фильтр кейсов (`abCaseFilter`-инлайн через `.ab-case-tab`),
                                 exit-intent попап
/js/forms.js                  — отправка форм на Web3Forms для root (и будущего /en/) — БЕЗ вызова Метрики,
                                 просто пушит `form_sent` в dataLayer (его слушает GTM, см. раздел 8)
/js/cookie-consent.js         — баннер cookie для root (и будущего /en/) — гейтит загрузку **GTM**, не Метрики
```

## 3. Новая международная главная (`/index.html`) — что на ней есть

Полное постраничное содержание — в брифе (`Главная страница alex-belyakov прототип v1.2.docx`). Коротко, сверху вниз:

1. **Шапка** — имя/подпись «Digital-маркетинг и платный трафик», нав (Услуги/Кейсы/Обо мне/Контакты), переключатель **RU|EN** (см. раздел 5 — EN пока не собран), иконки Telegram/WhatsApp/LinkedIn (`linkedin.com/in/aleksandr-beliakov-digital`, **без MAX и без телефона** — сознательное отличие от `/direct/`), кнопка «Получить консультацию».
2. **Hero** — заголовок «Платный трафик, который окупается. Яндекс, Google и вся воронка до заявки», 4 плитки цифр, фото + ряд пилюль-сертификатов (масштабируемый, не хардкод на 2 карточки, как на `/direct/`).
3. **«Где работает ваш бизнес»** — маршрутизатор, 2 карточки: Яндекс Директ (→ `/direct/`) и Google Ads (→ форма внизу, `#request`).
4. **«Что я делаю»** — 4 услуги сеткой 2×2, с чипами (масштабируемый список, не фиксированный).
5. **«Зона ответственности»** — 4 карточки, перенесены с `/direct/` почти без изменений (заголовок 2-й карточки — «Метрика и GA4»).
6. **«Ниши»** — 9 чипов, список открытый (добавлять — просто новый `<span class="ab-chip">`).
7. **«Компании»** — сетка из 10 плейсхолдеров (полосатая штриховка, как в дизайн-системе), 6 в ряд/3 на мобильном. Логотипы ещё не согласованы — см. раздел 10.
8. **«Кейсы»** — фильтр-табы (Все/Яндекс Директ/Google Ads/Аналитика и конверсия, класс `.ab-case-tab`, логика в `js/main.js`) + 7 карточек-заглушек с тегами `data-case-tags`. Детальных страниц кейсов для этой сетки пока нет (клика на карточку не ведёт никуда) — см. раздел 10.
9. **«Как проходит работа»** — 5 шагов, переиспользует ровно те же классы/JS, что и 6-шаговый процесс на `/direct/` (`.ab-process-grid.ab-process-row`, свайп и точки на мобильном — работают «из коробки»).
10. **«Формат работы»** — 4 плитки (Аккаунт ваш / Договор / 2 часа / Удалённо), тот же класс `.ab-numbers-row`, что и на `/direct/`, просто на одну колонку больше.
11. **«Обо мне»** — фото + переписанный текст под оба канала. Без мобильного «свернуть/развернуть» текста (в отличие от `/direct/`) — текст виден всегда.
12. **«Сертификаты»** — сетка на 3 колонки, сейчас 2 карточки (Директ Про, Метрика), плюс 4 закомментированных слота под будущие сертификаты Google Ads/GA4 — раскомментировать и вписать номер, когда появятся.
13. **«Форматы сотрудничества»** — 4 карточки (Директ/Google Ads/Аудит/Проектная работа), без цен (только «Помесячно»/«Разово» — валюта зависит от страны клиента, цену называют после разговора).
14. **FAQ** — 9 вопросов под международную аудиторию (другой набор, чем на `/direct/`).
15. **Отзывы** — тот же слайдер и те же 3 картинки, что на `/direct/`.
16. **Финальная форма** (`#request`) — поля: имя\*, контакт\*, ссылка (необязательно), комментарий (необязательно). Футер: без телефона, с LinkedIn (`linkedin.com/in/aleksandr-beliakov-digital`), нав включает пункт «Яндекс Директ» → `/direct/`, переключатель RU|EN продублирован.
17. **Sticky-бар снизу** (`.ab-sticky-bar`) — новый элемент, которого не было на `/direct/`: текст + «Написать в Telegram» / «Получить консультацию». Тело страницы имеет класс `ab-has-sticky-bar` (резервирует отступ снизу, чтобы бар не перекрывал последний блок).
18. **Exit-intent попап** (`#popup-exit`) — один на весь сайт, только десктоп (`hover:hover` + `pointer:fine`), один раз за сессию (`sessionStorage`), логика в `js/main.js` (мониторит `mouseout` с `clientY<=0`).

## 4. Формы на новой главной

Финальная форма (`#request`) и exit-intent попап шлют заявки через Web3Forms — **тот же access key, что у `direct`** (осознанный выбор, см. раздел 10). Поле обязательного контакта называется `contact` (не `phone`/`messenger`, как на `/direct/`) — это открытое текстовое поле (Telegram/WhatsApp/почта), формат не валидируется так строго, как телефон.

`/direct/index.html` сохранил все свои 6 форм (`form-request`, `forma-audit`, `forma-format`, `forma-obsudit`, `forma-audit-paid`, `forma-mediaplan`) без изменений — подробный разбор каждой смотри в README репозитория `direct`, раздел 3.

## 5. Языковой переключатель RU|EN — собран частично

По брифу нужно: `index.html` (RU, готово) + `en/index.html` (EN, прямой перевод, собирается ПОСЛЕ утверждения RU-текста — то есть намеренно не сейчас) + автоопределение языка по `navigator.language` с приоритетом ручного выбора через `localStorage`.

**Что сделано сейчас:** в шапке и подвале есть статичный переключатель `RU | EN` (класс `.ab-lang-switch`) — RU подсвечен, EN — обычная ссылка на `/en/`.
**Что НЕ сделано:** страницы `/en/` ещё нет (ссылка ведёт в 404), и автоопределение/redirect по `navigator.language` **намеренно не подключено** — включать его сейчас означало бы рисковать отправлять иностранных посетителей на несуществующую EN-страницу. Логику подключать вместе со сборкой `/en/index.html`.

## 6. Индексация поисковиками — по-прежнему полностью закрыта

Без изменений с прошлого раза: `<meta name="robots" content="noindex, nofollow">` на каждой странице (включая все в `/direct/`) + `robots.txt: Disallow: /` в корне. Сайт целиком, вместе с `/direct/`, не готов к публикации в поиске.

## 7. Что берём с `direct` 1:1, а что — нет

**Общее (шарится между root и `/direct/`):** `css/style.css`, `js/main.js`, `images/`, `favicon.ico`, `privacy.html`, `thanks.html`, `404.html`.

**У `/direct/` — своё:** `js/forms.js` и `js/cookie-consent.js` (другая аналитика, см. раздел 8), сам `index.html` (другое позиционирование, другие тексты, другой набор форм/попапов), `cases/*.html` (переехали из корневого `/cases/` — тот путь больше не используется).

**Не перенесено вообще** (ни в root, ни в `/direct/`) — то же самое, что было решено раньше при первом клонировании: `new.html`, `pilot.html`, `sitemap.xml`, файлы подтверждения прав на домен (`yandex_*.html`, `google*.html` — они принадлежат `direct.alex-belyakov.com`, для `alex-belyakov.com` нужны новые, см. раздел 10).

## 8. Аналитика — root и `/direct/` работают по-разному, это намеренно

- **Корень (`index.html`, будущий `/en/`)** — только **Google Tag Manager** (`GTM-W7RNPJSZ`). Подключается не напрямую в HTML, а через `loadGTM()` в `/js/cookie-consent.js`, гейтится баннером согласия на cookie (см. предыдущую версию этого README или commit-историю за 2026-09-14 за подробностями механизма). `form_sent` в `dataLayer` — триггер для тегов GTM.
- **`/direct/`** — только **прямая Яндекс.Метрика**, id `111606163` (тот же счётчик, что на живом `direct.alex-belyakov.com`). Гейтится тем же баннером cookie, но версией `/direct/js/cookie-consent.js`, которая грузит Метрику, а не GTM. `/direct/js/forms.js` при успешной отправке любой формы дополнительно дёргает `ym(111606163, 'reachGoal', 'form_sent')`.
- **JivoChat** — общий виджет на всех страницах домена, включая `/direct/` (тот же код `code.jivo.ru/widget/ufWAawj4Vq`).

**Не путать эти две ветки аналитики между собой** — это финальное разделение (см. память Claude Code `analytics_split_direct_vs_main`), а не незавершённая миграция.

## 9. История клонирования с `direct` (2026-09-14, для контекста)

Сайт был полностью склонирован с репозитория `direct` как рабочий каркас, затем `index.html` того клона перенесён в `/direct/`, а на его месте в корне собрана новая международная главная (см. разделы 1–3). При переносе в `/direct/`:
- Счётчик Метрики оставлен родным — `111606163` (тот же, что на `direct.alex-belyakov.com`), Web3Forms access key — тот же, что у `direct`.
- Пути переведены на абсолютные (`/css/...`, `/images/...`, `/direct/js/...`, `/direct/cases/...`) — при клонировании файл лежал в корне, теперь на уровень глубже.
- `og:url`/`og:image` и ссылка на политику в `privacy.html` — поправлены на `alex-belyakov.com` (были `direct.alex-belyakov.com`).
- Файлы подтверждения прав на домен `direct.alex-belyakov.com` — не скопированы (см. раздел 7).
